## 💫 About Me

I'm an AI engineer who builds LLM systems that go into production and then have to keep working — a different problem from building ones that demo well.

Most of my time goes on the unglamorous half: evaluation harnesses, retrieval that doesn't quietly fail on long documents, and the guardrails that make an agent safe enough to deploy somewhere the output actually matters. My last eighteen months were in investment-banking technology, where a confidently wrong answer was a compliance problem rather than a bug.

**How I think about this work:**
- 📊 Aggregate accuracy hides the failures that matter — break it down by class.
- ✂️ Draw the line between what the model decides and what your code decides, deliberately. Most agent failures are that line drawn in the wrong place.
- 🧪 Build the eval before the system. I didn't, and it cost me three months.

🎓 MSc Artificial Intelligence (Distinction), Queen Mary University of London
🔭 Currently open to AI Engineer / GenAI roles in London

## ⚡ Selected Work

- 🏦 **Agentic contract-review platform** — designed a RAG + agentic workflow on Claude, wired into a FastAPI backend with human-in-the-loop oversight; built a 500-document evaluation harness that raised accuracy from **70% → 80%**.
- 📄 **Production RAG pipelines** — shipped ingestion → embeddings → hybrid retrieval → grounded answering, integrated into enterprise systems via REST APIs, with CI/CD and containerised deploys.
- 🔍 **Reliability engineering** — added predictive monitoring and anomaly detection to backend services, cutting operational incidents by **45%**.
